## 🚀 Quick Start

```bash
git clone https://github.com/oovaa/javacode.git
cd javacode

# Compile and run a specific file
cd 8puzzle
javac *.java
java Main

# Or use Maven/Gradle for structured projects
cd "Pattern Recognition"
./mvnw test
```
